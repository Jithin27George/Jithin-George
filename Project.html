Hexapod Autonomous Navigation

SLAM + MPC on a six-legged robot using ZED stereo camera and ROS2. Real-time pose logging, obstacle avoidance, and dynamic gait control.

Solar Hybrid Atmospheric Water Generator

A solar-hybrid atmospheric water generator uses solar thermal and electrical power with silica-gel adsorption and Peltier condensers to quietly produce up to 0.9 L/hr of potable water from humid air, offering a compact, energy-efficient alternative to vapor-compression systems.

Quadrotor Navigation with Reinforcement Learning

A custom simulation environment was built with stable\_baselines3, featuring state and reward functions that guide the drone toward a target while safely avoiding obstacles. The Proximal Policy Optimization (PPO) algorithm was then used to train an agent end-to-end—hyperparameters were tuned, training curves monitored, and performance validated—to achieve smooth, reliable flight paths across a variety of simulated scenarios.

Q-Learning with Neural Networks for Inverted Pendulum

This project applies Q-learning with neural network function approximation to the inverted pendulum control problem. A PyTorch-based model approximates Q-values, and a policy is trained to minimize a predefined cost function. Deliverables include the full algorithm implementation, performance analysis through cost and value-function plots, and a demonstration video showcasing the pendulum’s behavior.

Grid-World: Value Iteration and Policy Iteration for Optimal Control

This project explores solving a Grid-World problem using Value Iteration and Policy Iteration algorithms to compute the Optimal Policy and Value Function. The project compares the computational complexity and convergence behavior of the two methods, providing insights into their application in real-world Optimal Control problems.

Trajectory Optimization and Model Predictive Control for 2D Quadrotor

A control system was developed for a 2D quadrotor to execute a looping maneuver using optimization-based methods. Trajectory planning is performed via Sequential Quadratic Programming (SQP), and the approach is extended with Model Predictive Control (MPC) to ensure real-time adaptability and robustness in simulation.

Implementation of SQP for Nonlinear Optimal Control

A Sequential Quadratic Programming (SQP) solver is implemented to tackle a nonlinear optimal control problem for pendulum dynamics. By discretizing the system and applying optimization routines, the solver drives the pendulum to a target configuration with minimal energy expenditure and high-precision control.

Visual Navigation and Embodied AI

This project implements an embodied AI agent capable of navigating a maze using visual input alone. The agent uses a camera feed to perceive its environment, extract semantic features, compute the optimal path, and autonomously navigate toward a goal.

Tag-based Augmented Reality: AR Cube Projection on ArUco Markers

This project implements tag-based augmented reality using ArUco markers. It detects and identifies markers in the camera feed, computes each marker’s pose, and superimposes 3D models—like a cube—onto them. Built with OpenCV, the system handles intrinsic camera calibration, defines marker dimensions, and performs precise pose transformations to ensure accurate AR overlays from multiple viewpoints.

RANSAC-Based 3D Plane Fitting for Point Cloud Data

A RANSAC-based plane-fitting pipeline was developed for 3D point clouds, iteratively sampling points and classifying inliers to robustly estimate plane parameters despite outliers. Adaptive sampling strategies optimize the computation, and results are visualized in Open3D—with inliers rendered in red and outliers in green—to clearly highlight dominant planar structures for computer vision and robotics applications.

Latent Embeddings & Classification

An autoencoder was used to compress Fashion-MNIST images into a compact latent space, then t-SNE projections revealed well-separated clusters corresponding to each class. A lightweight classifier trained on those latent representations achieved 85.48 % test accuracy, exhibited stable loss/accuracy curves, and highlighted a few illustrative misclassifications.

ICP-Based 3D Point Cloud Alignment Using Open3D

An Iterative Closest Point (ICP) pipeline was built to register 3D point clouds by iteratively refining rigid-body transformations from point correspondences. The work comprises two experiments—one on Open3D’s sample clouds and another on the KITTI driving dataset—leveraging centroid alignment, correspondence matching, and SVD-based rotation estimation. Convergence of the mean-square error is tracked to assess performance, and the resulting alignments are compared to highlight ICP’s accuracy, robustness to noise, and practical limitations.

F-Matrix and Relative Pose Estimation for Stereo Vision

A pipeline was developed to compute the Fundamental Matrix and recover relative camera pose (rotation and translation) from two stereo images using ArUco markers for robust point correspondences. RANSAC filters out mismatches and yields an accurate F-Matrix, whose epipolar constraints are visualized by overlaying epipolar lines on the images. The Essential Matrix is then derived and decomposed to extract the rotation (R) and translation (t) between views, with visual feedback validating the quality of the estimated parameters.

Object Tracking: Sparse and Dense Optical Flow

An object-tracking pipeline was built to follow targets across video sequences using optical flow. Both Lucas–Kanade’s sparse method and Farneback’s dense algorithm are implemented to enable persistent bounding-box tracking and motion-field visualization. The project compares each method’s efficiency and accuracy, providing detailed, step-by-step explanations and empirical results.

Skiptrace: Visual Place Recognition for Surveillance

A Visual Place Recognition pipeline was developed to match query images against a surveillance photo database using feature-based techniques. The system extracts SIFT descriptors, encodes them via VLAD, and applies k-means clustering for efficient indexing. This structured workflow covers feature extraction, descriptor aggregation, query processing, and visualization of retrieved matches from large-scale datasets.

Vision and IMU Fusion with Unscented Kalman Filter (UKF)

An Unscented Kalman Filter (UKF)–based sensor fusion framework was developed to merge IMU readings with vision-derived measurements for more accurate robot state estimation. The UKF was chosen for its ability to handle nonlinear system dynamics and limited observations. Two evaluation scenarios were implemented—one using visual pose data for position and orientation, and another using optical flow to supply velocity measurements. Estimated trajectories were then compared against ground-truth data, demonstrating the UKF’s superior performance in managing nonlinearities and sparse measurement inputs.

Robotic Kinematics and Visualization

A forward- and inverse-kinematics engine was implemented to compute precise joint angles and end-effector poses for robotic manipulators, with results rendered as a “connect-the-dots” stick-figure model. The system features robust error handling for unreachable target configurations and modular components covering forward-kinematics calculation, inverse-kinematics solving, and real-time visualization.
